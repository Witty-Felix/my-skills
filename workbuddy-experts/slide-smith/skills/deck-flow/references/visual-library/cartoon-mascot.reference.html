— 基准 —

一把尺子

Reference Transparency

它是什么

一条不过任何处理的参考链。切到它，你听到的就是原始录音本来的样子。

它不修饰、不补齐、不增宽——所以能当尺子。

怎么用（三步）

① 切到 Reference 听一分钟
② 切回处理链对比
③ 差别越明显，越该回头调

三步都不用记参数。

它不是「最好听」，它是「最真」——尺子不负责好听。

这两个坑，踩过的人都沉默了

坑 01

开太宽，声音变「隔墙」

阶梯直接拉满 → 人声跑到隔壁房间。正确姿势：一次一档，每档听一分钟。

坑 02

拿它修「耳机坏了」

单边没声音是硬件问题。效果器管「怎么听」，不管「听不听得到」。

诚实话：某第三方预设的兼容性未经确认，装前先备份配置。
