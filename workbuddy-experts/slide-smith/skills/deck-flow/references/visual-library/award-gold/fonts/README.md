## 使用约束

1. **庞门正道粗书体**：仅限个人学习 / 非商业演示。对外交付、客户提案、商业发布前，必须①购买商用授权，或②替换为已授权字体（推荐 `Noto Serif SC` 900，风格接近且 OFL 免费商用）。
2. **阿里妈妈数黑体**：可免费商用，但不得单独售卖字体本身；随包分发时保留本说明。
3. 字体文件**只允许被本皮引用**（`--ag-font-display` / `--ag-font-body`），其他皮引用即跨皮共享资产，违反 `_style-contract.md` §三。
4. 若替换字体，同步改 `award-gold.reference.html` 的 `@font-face` 与 F 层变量，并在此表更新许可状态。
