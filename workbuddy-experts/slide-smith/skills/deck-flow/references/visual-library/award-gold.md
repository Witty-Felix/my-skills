# award-gold · 鎏金颁奖

参考实现：`award-gold.reference.html`（5 屏，内容虚构脱敏：星辰之夜 / 望舒 / 临风 / 云旗 / 沐橙 / 白鹿 / 青梧 / 英雄之城）

## 1 调性

一句话内核：**深色鎏金氛围 + 三层文字节奏（金标题 → 白英文注 → 黄人名）+ 图贴边、文分区**——像颁奖典礼现场，观众席是暗的，聚光灯打在金色奖杯和获奖名字上。

不适合场合：轻松吐槽向内容、浅色品牌调性、需要信息密度高的分析汇报。

| 变量 | 色值 | 用途 |

| `--ag-gold-lo` | `#B87A1E` | 鎏金渐变暗端 |
| `--ag-gold-mid` | `#E0A338` | 鎏金渐变中间档（`--ag-grad-gold` 72% 处） |
| `--ag-gold-sub-hi` | `#FFEDB0` | 副题渐变亮端（`--ag-grad-sub`） |
| `--ag-gold-sub-lo` | `#D89A35` | 副题渐变暗端（`--ag-grad-sub`） |
| `--ag-yellow` | `#FFEC00` | 聚光黄：**仅人名、名次、数字**，一页唯一纯色焦点，面积 < 15% |
| `--ag-yellow-hi` | `#FFF6C8` | 结尾页笔刷渐变亮端（`.ag-brush--end`） |

| `--ag-white` | `#F5F0E6` | 暖白：英文注、奖励行 |
| `--ag-ink` | `#1A0E04` | 深棕黑底兜底色（背景图加载失败时）+ 侧图层内侧渐变 |
| `--ag-ink-cover` | `#12081C` | 深紫黑（封面/结尾兜底色） |
| `--ag-ink-warm` | `#2A1608` | 侧图层外侧渐变（暖棕） |

渐变配方（组件里只引用，不写裸 HEX）：

```css
--ag-grad-gold:linear-gradient(180deg,var(--ag-gold-hi) 0%,var(--ag-gold) 42%,var(--ag-gold-mid) 72%,var(--ag-gold-lo) 100%);  /* 标题鎏金 */
--ag-grad-sub:linear-gradient(180deg,var(--ag-gold-sub-hi) 0%,var(--ag-gold) 60%,var(--ag-gold-sub-lo) 100%);                  /* 副题鎏金 */
```

用法约束：金做骨架、黄做爆点；没有第四种彩色（红绸/青色只允许出现在图片素材内部）；背景必须亮而有影（brightness ≈ 1.2×），不死黑。

## 3 字体（F 层，前缀 `--ag-`）

| 变量 | 字体 | 许可证 | 文件 |
|---|---|---|---|
| `--ag-font-display` | 庞门正道粗书体（替代付费的「字魂白鸽天行体」，粗笔毛笔气质接近；客户有授权可换回，版式不变） | 免费商用 | `award-gold/fonts/PangMenZhengDaoCuShu.ttf` |
| `--ag-font-body` | 阿里妈妈数黑体 | 免费商用（官方授权） | `award-gold/fonts/AlimamaShuHeiTi-Bold.woff2`（ttf 兜底） |

规则：数黑体贯穿全 deck，手写体只在封面/结尾出场——「黑体是语言，手写体是情绪」。标点（【】、—）单独用系统雅黑加粗混排，避免标点发虚。

## 4 字号阶

| 用途 | 字号 | 颜色 | 备注 |

| 封面/结尾大字 | 150–166px 逐字混排 | 鎏金渐变 / 结尾可用聚光黄 | 每字字号不同制造节奏（如「市」166/「场」138） |

| 副标题 | 40px | 主金鎏金 | 加粗，字距 10px |
| 顶部标签 | 36px | 主金 | 格式 `—标签词—`，可选层 |
| 英文注 | 24px | 暖白 | **全大写 + 宽字距（letter-spacing:.3em）** |

## 5 视觉语法

- **鎏金渐变标题**：`background:var(--ag-grad-gold)` + `background-clip:text` + `color:transparent`，外挂 `drop-shadow(0 4px 10px rgba(0,0,0,.65)) drop-shadow(0 0 30px rgba(255,200,70,.4))` 模拟鎏金浮雕辉光。
- **人名辉光**：黄平涂 + `text-shadow` 金色 glow，让爆点"发光"。
- **背景提亮**：背景图 `filter:brightness(1.18) saturate(1.15)`（封面）/ `brightness(1.2)`（内页），隆重感来自"亮而有影"。
- **侧图过渡带**：贴边实拍图两侧用 inset box-shadow 压出深色渐变过渡（`--ag-ink` 内侧 / `--ag-ink-warm` 外侧），保证文图物理分离。
- **装饰只有两件**：① 金色分隔线（带三颗星星，封面/结尾副题下）② `—短横线—` 顶部标签。没有边框、色块、圆角矩形。
- **背景构图公式**：暗底 60% + 光斑星尘 25% + 底部金色 glitter 光带 15% + 一个角落视觉锚点。一本 deck 所有内页共用同一张背景，封面/结尾用另一张。

## 6 安全区与栅格

- 画布 1280×720，标题块垂直位置 y ≈ 22%–60%，人名紧贴标题下，行距 ≈ 1.1。
- **图永远贴边**：侧图宽 38%、满高出血（top:0;bottom:0），至少一边贴画布边缘，绝不悬浮居中。
- **文字区 = 剩余 62%**，图与文之间由过渡带分隔，**文字永不压图**。
- 对齐规则：**多行名单（≥2 行）左对齐；单奖项/单行居中**——跟信息量走，不跟图方向走，一页内不混用。

## 9 坑

1. **图别用错**：`ag-photo-cup` 必须是实拍（FIFA 大力神杯），卡通 BEST 贴纸是 `ag-sticker-cup`（趣味奖专用）——**正式度 = 图的写实度**，卡通奖配实拍图/实拍奖配卡通图都违和。图必须能被标题"解释"。
2. 背景图 `bg-gold`（含"颁奖典礼"书法字）**不可当背景复用**，只能用 `ag-bg-inner`（干净 bokeh 底）。
3. 黄色只给人名和数字；用在标题或长句立刻破功。
4. 封面大字必须逐字混排字号（span 包裹），整块同字号就没有原稿的节奏感。
5. 截图验证必须等入场动画完成（headless 用 `--virtual-time-budget=4000`），否则截到半透明暗帧。
6. headless 跳页锚点是 `#4` 这样的**纯数字**（对应 `go(n)`），不是 `#s4`。
7. 英文注必须全大写 + 宽字距；小写紧字距即翻车。
