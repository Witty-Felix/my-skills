## 0 签名表（L2 隔离判定依据）

| 要素 | 本皮 | 强度 |
|---|---|---|
| 描边结构 | **无描边**（卡片 0px），层次靠柔影 + 底色块 | **强** |
| 投影方式 | **柔影** `0 6px 18px rgba(63,70,113,.14)`，无硬边 | **强** |
| 强调载体 | **深色承载块 + 反白标题** / 半透明大数字 | **强** |
| 旋转 | 0（禁） | 弱 |
| 圆角 | 卡 8px / 块 16px / 圆点 999px（两级系统） | 弱 |
| 纹理 | 无；图案只出现在「画格墙」「书签边」两类装置 | 弱 |

> 三强项与 `pop-collage`（单线 3px / 硬偏移影 / 斜贴标签）、`cartoon-mascot`（双线包边 / 零影 / 白底旁白框）**全部不相同**。
> 旋转与圆角是弱项：本皮与 `cartoon-mascot` 同为「禁旋转」，靠强项区分，不靠这两项。

## 1 调性

一句话内核：**一个蓝紫单色调的贴纸世界——深色块压住信息，白色只给卡和字，角色永远从画面边缘探出来半截。**

不适合场合：严肃数据汇报、黑白打印为主的场合（单色调依赖屏幕发光）、需要冷静克制的场合。

## 2 色板（S 层，前缀 `--ss-`）

| 变量 | 色值 | 占比 | 用途 |
|---|---|---|---|
| `--ss-bg` | `#C8D0EE` | ≈34% | 全篇底色 |
| `--ss-board` | `#5A5F9C` | ≈30% | 深色承载块、标题条、章节页右栏、图表区底 |
| `--ss-board2` | `#7B84B8` | ≈8% | 画格墙底、次级色块 |
| `--ss-paper` | `#FFFFFF` | ≈14% | 卡片、标题字、爆炸框 |
| `--ss-ink` | `#3F4671` | ≈6% | 正文深色字、插画描边、虚线框 |
| `--ss-ink-mute` | `#6E76A6` | ≈6% | 次要文字、图注 |
| `--ss-pink` | `#F7C6CE` | ≈1.5% | 腮红、爱心（暖色点缀） |
| `--ss-yellow` | `#F3D089` | ≈1.5% | 小鸭、草帽、冰淇淋（唯一暖色的另一半） |

用法约束：
1. **暖色总量 ≤5% 画面**（`--ss-pink` + `--ss-yellow` 合计），超了就破单色调。
2. 深色块内文字只允许 `--ss-paper` 或 `--ss-bg`，不允许第三色。
3. 浅底上不允许浅字：正文最低对比为 `--ss-ink` on `--ss-bg`。

## 3 字体（F 层，前缀 `--ss-`）

| 变量 | 字体 | 字重档 | 许可证 |
|---|---|---|---|
| `--ss-font-display` | Noto Sans SC / 思源黑体 | 900 | OFL，系统或 Web 字体 |
| `--ss-font-body` | Noto Sans SC / 思源黑体 | 400 / 500 | OFL |
| `--ss-font-hand` | 系统手写体（fallback: 楷体） | 400 | 仅 p11 装饰用 |

族名原图不可判，取近似三选一：思源黑体 Heavy / 阿里巴巴普惠体 Heavy / 汉仪旗黑。

## 4 字号阶

| 用途 | 起值 | 字重 | 行高 |
|---|---|---|---|
| 封面主标题 | 62px | 900 | 1.15 |
| 章节大数字 | 200px，白色 20% 透明 | 900 | 1 |
| 章节标题 | 48px | 900 | 1.3 |
| 页标题 | 34px | 900 | 1.3 |
| 卡标题 / 列表 | 24px | 900 | 1.4 |

| 正文 / 注释 | 17px | 400 | 1.9 |

## 5 视觉语法

```css
/* ① 深色承载块（无影、16 圆角） */
.ss-board{background:var(--ss-board);border-radius:16px;box-shadow:none}
/* ② 白卡（柔影、8 圆角） */
.ss-card{background:var(--ss-paper);border-radius:8px;
  box-shadow:0 6px 18px rgba(63,70,113,.14)}
/* ③ 角色贴纸：6px 白边 + 柔影，白边用四向 drop-shadow 伪造，不增加位图 */
.ss-sticker img{filter:
  drop-shadow(3px 0 0 #fff) drop-shadow(-3px 0 0 #fff)
  drop-shadow(0 3px 0 #fff) drop-shadow(0 -3px 0 #fff)
  drop-shadow(0 10px 18px rgba(63,70,113,.22));}
/* ④ 半透明大数字 */
.ss-mega{font:900 200px/1 var(--ss-font-display);color:rgba(255,255,255,.20)}
/* ⑤ 虚线框正文 */
.ss-dash{border:2px dashed rgba(255,255,255,.55);border-radius:8px;padding:20px}
```

比例纪律：
- 边距 `5.6%W` / `6.6%H`（1280×720 即 72px / 48px）
- 栏间距 `2.2%W`（28px）
- 角色三尺度：主角 300–420px｜陪伴 120–140px｜点缀 80–100px（**导入规则**，见 §11）
- 图文间距 ≥3%W

## 6 安全区与栅格

- 舞台固定 1280×720 + `transform:scale()` 等比缩放，禁 `clamp()/vw`。
- 内容安全区：x 72–1208，y 48–672。
- **角色可破框，文字绝不破框**：破框只允许出现在画边（上/下/左/右），不允许压进文字块内边距。
- 顶部 0–200px 只允许主角或空。
- 每页只允许一个深色承载块。

## 9 坑

1. **暖色超 5%**：加一只鸭子、再加一个冰淇淋，两页就把单色调破了——暖色按页配额，不按张。
2. **贴纸白边用 `filter:drop-shadow` 四向伪造时**，投影必须单独再加一条且方向朝下，否则贴纸贴地感消失。
3. **深色块里再放白卡**：白卡会失去柔影，看起来像贴了个洞——深色块内只放虚线框或纯文字。
4. **半透明大数字压在深色块上会消失**：它只能压在浅底上，或改成白色 12% 压深底。
5. **角色破框只破一次**：一页两处破框（如右上 + 底部）会让人觉得没排完。
6. **圆角混用**：卡 8 / 块 16，不许出现 12 或 24——两级之外都是错。
7. **卡片下半截不许空**：纯文字卡在大屏上会读成「没做完」。每张卡必须给一处视觉锚点——头肩小图（推荐）、色块或大号数字。样张 11 页里 **100% 的卡都有插画**，这是它不显单调的直接原因。
8. **卡内图像只能用头肩裁切**：全身姿态塞进 263×356 的卡里会变成「小人站在卡里」，尺度失准；只取头部与肩（横向中间 56%、纵向顶部 52%）才读得对。
9. **出页前过一遍「单调七条」**：见 `../../../../docs/升级草案-视觉皮完全隔离-v3.3.md` 附则 A。挂了 2 条以上就重排版式，不许加装饰抢救。
10. **贴纸必须「搭」在东西上**：每件贴纸要能答出它是承载 / 关联 / 接触中的哪一种，答不出就是悬空。判据与阈值见附则 B，实施参数见 §14。

## 11 从 cartoon-mascot 导入的六条规则（结构纪律，不涉视觉几何）

| # | 导入项 | 在本皮怎么落地 |
|---|---|---|
| 1 | **角色三尺度**：主角 300–420 / 陪伴 120–140 / 点缀 80–100，同页最多两档 | 保持原值；主角用于 P1/P3，陪伴用于 P4/P6，点缀用于 P8/P10 |
| 2 | **句型 → 动作映射** | 旧的三姿态（指向/思考/慌张）**已退役**，改为本文件 §12 的六式 |
| 3 | **方向三问**：面朝哪边 / 手势指向哪边 / 与版面语义是否一致；不一致先挪位再镜像 | 上页前逐页过；**外加第四问：她跟什么东西挨着？** |
| 4 | **安全区纪律**：固定舞台、角色不进文字内边距、顶部 0–200 只允许主角或空、叠压方向恒定（角色在内容块之上） | 保持 |
| 5 | **视觉预算守恒**：一页 100 分，背景分高的前景就拿不到；没有一页允许「背景花 + 前景也花」 | 重装置页（P1/P3/P5）前景只留标题与一个角色 |
| 6 | **组件闭集 + 前缀 + 登记后使用**：`.ss-*` 之外不许现场造类 | 新增类先回到本文件 §7 登记 |

**没有导入的**（与贴纸风冲突）：双线包边、直角、零影、砖墙纹、白底旁白框、禁圆角。这几条留在 `cartoon-mascot`，不跨皮。

## 12 动作系统（替换 cartoon-mascot 三姿态）

> 依据 `../../../../docs/动作提取-呆呆鲨卡通风.md`（11 页取证）。
> **核心判断：这份样张的角色从来不站着。9/9 页角色都与某个元素发生物理接触。**

### 12.1 六式

| 式 | 定义 | 用在 |
|---|---|---|
| 抱 HOLD | 双臂环抱道具，道具占画面 ≥12% | 封面 / 主张 |
| 举 RAISE | 单臂上举，道具高于头顶 | 目录 / 清单 |
| 趴 LIE | 躯干压在一条水平边上 | 定义 / 说明 |
| 套 RING | 身体穿过环形物，环遮腰或肩 | 数据 / 量级 |
| 罩 COVER | 道具从上方扣住头部，只露脸与手 | 警告 / 坑 |
| 探 PEEK | 被画边或块边缘裁掉半个身子 | 结尾 / 收束 |

### 12.2 硬参数

| 项 | 值 |
|---|---|
| 躯干倾角 | 8–18°（趴式可至 80°）；**禁止 0° 正立** |
| 重心 | 偏移 ≥ 体宽 1/5，超出支撑面 |
| 承托物 | **每张必须与某个元素接触**（版面块/道具/画边），接触率目标 100% |
| 手部 | 3 指以内或鳍状；不画五指定型 |
| 腿/尾 | 简化为一团，无关节转折 |
| 头身比 | 约 2 头身，头占全高 45–50% |
| 腮红 | 必出现，两团，直径 ≈ 头宽 12% |
| 表情 | 眯眼笑 / 张嘴笑 / 闭眼满足 / 睁圆呆萌 / 张嘴慌张 |
| 视线 | 与文字区相反（角色看留白，不看字） |
| 破框 | 全书 50–60% 的页面允许一处破框 |

### 12.3 退役

`cm-char-point` / `cm-char-think` / `cm-char-panic` 三张**不再作为本皮素材**。
在新姿态图就位前，只允许用「趴 / 探」两种构图改造现有图（做法见动作提取文档 §7）；
**抱 / 举 / 套 三式必须有道具，构图伪造不出来，需重新绘制。**

### 12.4 第四问

上页前除「面朝哪边 / 手势指向哪边 / 语义是否一致」之外，加一问：

> **她跟什么东西挨着？** 答不出来，这张姿态就是废的。

## 13 道具库（第三种主体）

> 起因：14 页出完后用户说「角色行为还是比较单调，可以有更多小物件」。
> 角色只有六式，反复用会疲；**道具是给角色加动作、也给自己加主体的第二条路。**

### 13.1 待入库（第一批，`soft-sticker/assets/prop-*.png`）

> ⚠️ 下表是**待绘制清单**，当前包内还没这些文件。本皮 §12.3 已退役三张旧角色图，`assets/` 目录暂空；道具图缺位时，用卡通形象皮已有的角色图**改造构图**（趴 / 探两式），不要拿 `cartoon-mascot/assets/` 的图直接当本皮素材。

| 道具 | 语义 | 用法 |
|---|---|---|
| 头戴耳机 | 主题本身 | 封面抱持；或单放当页首图标 |
| 鲸鱼玩偶 | 陪伴 / 旁听 | 填空位、跟在角色旁、无角色页当主体 |
| 小喇叭 | 强调 / 警告 | 坑页、结论页 |
| 音量旋钮 | 调节 / 响度 | 夜间、Levelizer 类内容 |
| 音符 | 声音本身 | 串扰、HRTF、音乐场景 |
| 短尺 | 基准 / 测量 | 参考档、对比 |

### 13.2 用法纪律

1. **道具是「第三种主体」**：与角色、大面积色块并列。一页里三者至少出现一个——这直接对应附则 A 的「遮主体测试」。
2. **一页最多 2 件**；尺度 90–160px。超过两件就变成贴纸堆。
3. **必须同源**：描边 5px、白边 6px、色板只看 `--ss-*`。外部图标（线条图标、emoji）一律不许进。
4. **道具可替代角色承担语义**：没有角色的页，用一件道具放在视觉落点上即可，不必硬塞一个人。
5. **道具与角色要发生关系**：鲸鱼游过两块之间的缝、音符飘在摊着的角色上方、旋钮被角色扶着——**不要把道具和角色各摆一边**。

### 13.3 生成方式（省钱）

一次生成一张 **3×2 道具表**（纯白底、等距、不重叠），再用脚本按格切片 + 抠白。
单张约 5–10 积分，比逐件生成省 5 倍。切片要点同 §12.3：先抹棋盘灰再 floodfill。

## 14 位置关系（文字 / 角色 / 道具）

> 判据、阈值来源与验收：`../../../../docs/升级草案-视觉皮完全隔离-v3.3.md` **附则 B**。
> 本节只保留**本皮的实施参数**（z 值、px、栅格、关系分型）。两处冲突时**以附则 B 为准**。

> 起因：14 页定稿后复查发现，音符、齿轮悬在纯背景里，枕头离角色还有一段缝，结尾角色压着 HUD。
> 共同点：**元素都在，但相互关系没规定**。本节把「谁挨着谁、挨多近、谁压谁」写成可判定的数。

### 14.1 四层与 Z 序（不可越级）

| 层 | z-index | 成员 | 备注 |
|---|---|---|---|
| L1 底 | 0 | 背景色、画格墙、薄纱 | 永不被压 |
| L2 承托 | 2–4 | 深色块、白卡、顶条、结句条、虚线框 | 承载信息 |
| L3 贴纸 | 5–9 | 角色、道具 | 恒在 L2 之上 |
| L4 引擎 | 70 / 80 | 讲稿抽屉、HUD | 永不被压 |

三条硬规矩：
1. **L3 恒压 L2**；唯一例外是刻意的「藏在卡后」——此时 L3 的 z 降到 1，但**必须仍露出 ≥60% 的头部**。
2. **道具不许压角色的脸**：眼睛到嘴的矩形范围是禁区，压住即判不合格。
3. **L4 是「文字禁区」**：右下 `190×44` 与底部讲稿抽屉里**不得放任何文字**。
   角色可以延伸到该区域之后（破底时几乎无法避免），但**脸与手必须在其外**——被 HUD 压住脸，等于这页废了。

### 14.2 落点律（最关键的一条）

**任何贴纸都必须"搭"在某个东西上，不许漂在纯背景中央。**

| 贴纸尺度 | 必须满足 |
|---|---|
| 小道具 ≤120px | 与角色或某个版面元素的**间距 ≤24px** |
| 角色 | 与版面元素**接触**，接触面积 ≥ 自身面积 8%（压在卡沿、块沿、画边上） |
| 大角色 300–420px | 必须破框或压住一条边，不许整个浮在画面里 |

判定法（一句话）：**遮住这张贴纸，页面若毫无变化，它就没有落点，删掉或挪位。**

### 14.3 净距（一票否决项）

| 关系 | 最小净距 |
|---|---|
| 贴纸 ↔ 正文 | **24px** |
| 贴纸 ↔ 标题 | **32px** |
| 贴纸 ↔ 页码 / 图注 | 16px |
| 贴纸 ↔ 纸边 | 允许 0（破框），但**只允许一侧** |
| 卡内头肩图 ↔ 卡内边距 | 底对齐，左右居中，高度 ≤ 卡高 45% |

> 「压字」不是审美问题，是**一票否决**——压了就是 0 分，不管构图多好看。

### 14.4 破框

- 一页**只允许一处**破框（四边合计）。
- 裁切线必须穿过**躯干**（胸或腰），不许穿脸、不许穿手。
- 破框后仍须能看到 ≥60% 的头部。

### 14.5 三种关系，各有各的距离

| 关系类型 | 道具举例 | 判定 |
|---|---|---|
| **承载** | 水杯、枕头、尺子、书 | 必须落在一条**既有水平边**上（卡沿 / 块沿 / 基线 / 页底），不许浮空 |
| **关联** | 音符、星星、问号 | 距**角色头部 ≤120px**，且位于视线朝向那一侧 |
| **接触** | 角色 + 任意道具 | 间距 ≤24px，或重叠 5–20%（重叠超过 20% 就是遮挡） |

### 14.6 对齐

贴纸的水平锚点优先落在栅格线上：**72 / 363 / 654 / 945 / 1208**，允许 ±8px 的视觉修正。
不许出现「差 5px 谁也看不出来但就是歪着」的位置。

### 14.7 出页前自检（六问，同草案 B.4）

```
□ 遮住这张贴纸，页面有变化吗？——没有就是没落点
□ 它压字了吗？压脸了吗？——压了就是 0 分
□ 它是承载 / 关联 / 接触？三型都答不出 = 挪位
□ 它压的是该压的那层吗？——L3 压 L2，不反
□ 破框只有一处？裁切线在躯干上、头还露 60%？
□ 右下 190×44 里没有字、没有脸、没有手？
```

> 挂一问即重排，不许写进「下次注意」。机器可测的 P1–P6 见附则 B.3。
