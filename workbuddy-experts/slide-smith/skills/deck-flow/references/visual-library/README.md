# 视觉风格库

**这一层只管「长什么样」**：形状语言、装饰密度、留白节奏、字体性格、质感与抬升。
它**不管**论证怎么排、页序怎么走、证据要多硬——那是 `../style-library/`（表达方法）的事。

两者正交，可任意组合：`operating-review` 的骨架 + 深色科技的皮，或者 `mbb-consulting` 的骨架 + 波普拼贴的皮。

> **风格一律用中文名。** 下面表格的「风格」列是正式称呼，跟用户沟通只报中文名，不报英文 id。英文 id 只作文件名（`<id>.md`）与内部标识用，**不改名**——改了会断掉 `deckcore` 的引用。

> **「白底圆角卡片页」不在这里。** 那是 Step 3《逐页内容》这个交付物本身的固定形态（见 `SKILL.md` 3.2 与 `templates/逐页内容模板.html`），不是一种可选风格，也不参与 Step 4 的风格选择。别把它算进这 5 种。

## 一之二、对用户怎么摆（先开选型页，再问走哪条路）

**上面两张表是给你自己查的；对用户一律按这一节走——先给页面，不给文字清单（J-56）。**

### 第一步：打开选型页

开包内 `../../视觉皮选型页.html`，**原地打开、不复制**（J-49），交给用户。推荐位带 `?rec=<id>`。

正文只写两样：

1. **一句怎么用**：5 张卡，点缩略图在新标签打开整份示例稿，看完回来挑。
2. **一句推荐 + 理由**：按「场合 + 听众 + 表达方法」匹配度挑第 1 条。

> **⛔ 不许只列 6 行文字。** 用户原话：「你只给这个 HTML，给这个链接，不要只给文字」（J-56）。文字清单只在**页面打不开**时兜底。

### 第二步：弹卡片 A

页面给完之后弹（`header` 固定 `视觉皮`，两格：`从模板里选` / `我自己给参考`），同卡第二题问 `配图`：`不要图` / `少量配图` / `逐页配图`。**这张卡不许抢在页面之前发**——没看见有什么，没法判断要不要自己给参考（J-52）。

- 用户说「都不合适」→ 说明库里只有这 5 种，**转卡片 B 走岔 B**：请他给参考，或让你出试片，**不现编**。
- 页面上点了卡不算确认，仍等用户回一句话。

### 兜底：页面打不开时才用的文字句式

**只有在无预览能力 / 纯文本终端时才用这一段。** 单条句式（缺括号 = 不合格）：

```
3. 剪纸层叠（适合：亲子教育、公益、节日活动）— 层叠纸片、柔和层间投影、手感
```

- 括号里写**「什么时候该用它」**，用日常说法，不写术语。
- 破折号后写**「它长什么样」**，一句说完。
- 整条 ≤ 45 字。**只报名字 = 不合格。**
- 5 条全给、按匹配度排序，第 1 条即推荐。

### 末尾固定这一行（仅兜底时挂）

```
已给 5/5 · 全库就这 5 种，要别的得你给个参考
```

### 不参考模板时怎么走（岔 B）

用户选了「我自己给参考」，**再发卡片 B**（`header` 固定 `参考图`，问句「参考图谁来出？」）：

| 格 | 含义 | 你接什么 |
|---|---|---|
| 我自己出图发你 | 他手上已有截图 / 网站 / 现有 HTML | **停下等图**。图没到不发样张；卡片传不了文件，让他在聊天框发 |
| 你按内容生成几版我挑 | 要你先出试片 | 走 SKILL.md 4.1c |
| 我不确定，你先出 | 同上，但他还没想清方向 | 同上——**这一格就是「不知道参考什么」的入口**，不用猜他语气 |

**出试片的四条规格**（SKILL.md 4.1c 有完整版，这里是摘要）：

1. 取稿子的**封面 + 第一张内容页**，**标题 / 数字 / 正文一个字不动**，只换形状语言、装饰密度、字号阶、质感。三版都用真内容，否则比的是内容不是风格。
2. **3–4 版封顶**，一屏能并排比完。
3. 宿主 ImageGen 出图，**文字不进图**（试片里的标题也要原生文本，否则挑完没法改字）。
4. 挑完写 `ppt/<项目名>/临时视觉皮.md`（调性 / 色板三个 HEX / 字号阶 / 视觉语法 / 安全区），**不进包、不写进本目录**。反复用到同一套再问「要不要正式收进库」，那才走 §四 六步。

### 用户怎么答，你怎么接

| 用户说 | 做法 |
|---|---|
| 第 3 个 / 就要剪纸层叠 | 直接定，不再追问理由 |
| 还有别的吗 / 都不好看 | 说明库里只有 6 种、已全给过，**转卡片 B**：给参考或出试片，**不重复兜圈** |
| 你定 / 随便 | 取第 1 条，一句话说为什么 |
| 就这样 / 不用换 / 保持现在这个 | **不套皮**，直接沿用《逐页内容》的白底圆角卡片（J-29） |
| 跟上次一样 / 还是那个风格 | 取上次记录的那个，不重问 |
| 我不知道参考什么 | **卡片 B 第 3 格**，出 3–4 版试片（J-52） |
| 报英文 id | 对回中文名（英文 id 只作文件名，J-32） |

## 二、怎么选

1. **先定场合，再定气质。** 给谁看、在哪放、投影还是打印，决定能承受多少密度与装饰。
2. **不要按「好看」选，按「该让听众感到什么」选。** 要稳 → 剪纸层叠 / 手绘笔记；要冲 → 波普拼贴；要仪式感 → 鎏金颁奖；要亲和 → 贴纸插画。
3. **一层只选一个皮。** 一份稿子只允许一套视觉语法，混用会像出自不同的人手。
4. **没指定就问一句。** 按「一之二」**先打开选型页**再问；用户说「你定」就按场合最贴的选，默认回落波普拼贴。
5. **不换皮也是合法答案。** 用户说「就这样 / 不用换」→ 直接用 Step 3 那份白底圆角卡片，只做排版精修，不强行套任何皮。

### 组合规则

- 皮与骨架**各选一个**，互不影响。
- 走 PPTX 时**不交给任何人**：自己按这份皮的规格写 SVG，表达方法决定页序；引擎只做校验与转换。
- 用户要一个库里没有的皮 → 明说没有，请他给参考（截图 / 网站 / 现有 HTML），**不要现编**。

## 三、逐页生图时，风格怎么进 prompt

选定的皮要拆成 prompt 的四个要素，**每页只改「画什么」，不改「怎么画」**——否则 15 页会像出自不同的人手。

| 要素 | 从风格的哪来 | 例子（波普拼贴） |
|---|---|---|
| 质感 | 调性 | 波普拼贴、剪贴杂志感、贴纸感、有点吵 |
| 色板 | 色板那几个变量 | 奶油底 + 橙 / 钴蓝 / 黄，统一 3px 墨黑描边 |
| 图形语法 | 视觉语法 | 粗描边、硬投影、轻微旋转、半调网点 |
| 构图密度 | 安全区与页面原型 | 大标题占半版，留白大，不塞满 |

**文字不写进 prompt。** 生图只出视觉，页面上要读的字必须是原生文本框（见 J-18）。

## 四、加新视觉皮的规矩

1. 必须有一份**真实跑通的 HTML**（不是描述），命名为 `<id>.reference.html`。
2. 写 `<id>.md`，至少包含：调性、色板、字号阶、视觉语法、安全区、组件清单、页面原型、交互、坑。
3. **必须遵守 `_style-contract.md`**：E 层 7 个变量一个不少、S/F 层带 `<id>-` 前缀、私有类带 `<id>-` 前缀、资产进 `<id>/assets/`、字体只写获取方式。
4. 在本文档 §1.1 加一行（**风格列写中文名**）；若属于 catalog 家族，则在 `deckcore/references/visual-styles/_index.md` 登记。
5. 不要把新皮塞进旧皮的 md 里——一个文件只管一个皮；也不要把旧皮的资产挪来复用（契约 §三 第 5 条）。
6. **必须补 3 屏示例稿 + 首屏缩略图 + 选型页一张卡**：示例稿 `<id>.reference.html`；缩略图落 `_picker/thumb-<id>.png`（1280×720，单张 ≤200KB，照片类可转 `.jpg`）；同时在 `视觉皮选型页.html` 里加一张卡（中文名 / 适合 / 内核 / 色板 chips / 屏数）。**改了示例稿必须重截缩略图**——`thumb-<id>` 的 mtime 早于 `<id>.reference.html` 就是旧图。

这 2 种的 3 屏示例稿由本包自建（版式按 deckcore 规范，色板为示例实例），内容虚构，只演示风格落地，不是 original 样张。
波普拼贴为本包原创。鎏金颁奖、贴纸插画两张皮为本包原创，参考实现中的图片素材随稿虚构。
