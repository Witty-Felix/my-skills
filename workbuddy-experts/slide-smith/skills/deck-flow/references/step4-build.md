# Step 4.4 · 构建 HTML 放映页

> 本文件只管 **HTML 放映页** 这一条分支（SKILL.md 4.4）。
> 可编辑 PPTX 走 4.5、逐页生图 PPTX 走 4.6，两者都转内置 `ppt-master` 引擎。

前置：`<项目名>-逐页内容.html` 已通过审核，**视觉皮已在 4.1 问定**，**三页样张已在 4.2 确认满意**。

## 1. 起手

```bash
mkdir -p "<workspace>/ppt/<中文项目名>"
cp "<SKILL_DIR>/references/visual-library/<style>.reference.html" \
   "<workspace>/ppt/<中文项目名>/<中文项目名>-放映页.html"
```

**从参考实现改，不从零写。** 引擎、HUD、讲稿抽屉、`@page` 全都在里面，重写只会引入 bug。

> 目录名、文件名全用中文（J-27）。上例里的 `<style>` 是视觉皮 id，那是库内标识，保持英文。

> 本包自带四张皮里，**波普拼贴 / 鎏金颁奖 / 卡通形象**都带 `.reference.html`（在 `visual-library/`），**贴纸插画**规范齐全但参考实现待建。选其余 18 种 catalog 皮时没有可复制的参考稿：按该皮在 `deckcore/references/visual-styles/<id>.md` 的形状语言与留白纪律，自己搭一份 1280×720 固定舞台的骨架（键盘翻页 + `data-note` + `fit()` 缩放照本节规范），之后仍可复用。
>
> **不换皮时根本不走这一节**：直接拿 Step 3 的 `<项目名>-逐页内容.html` 当成品，只补讲稿交互与排版精修，不必从头搭骨架。

## 2. 清空内容，保留骨架

删掉所有 `<section class="slide">`，只留：

- `<style>` 全部（组件样式）
- `<div id="stage">`
- `<div class="hud">` 与 `<div class="notes">`
- `<script>` 全部

然后按 `<项目名>-逐页内容.html` 一页一页搬 `<section>`——**整页搬，不要重新排版**。取 `data-page` / `data-role` / `data-note` / `h2.at` 与整段内部结构，只换成目标皮的样式类。内容与版式的判断在 Step 3 已经做过了，这里不重做。

## 3. 每个 section 的结构

```html
<section class="slide s-<原型>" data-note="<讲稿原文>">
  <header class="hd r">
    <p class="kick">PART 01 · 小节名</p>
    <h2 class="ttl">结论式页标题</h2>
  </header>

  <div class="<组件> r">
    ...
  </div>

  <p class="note r"><b>注</b>补充说明</p>
</section>
```

三条硬规则：

1. **`data-note` 必须有**，没讲稿就写空字符串——HUD 会显示「本页无讲稿」，那是提示不是错误。
2. **需要动效的元素加 `.r`（带位移）或 `.rf`（只透明度）**。靠 `transform` 定位的块只能用 `.rf`。
3. **页序即《逐页内容》的顺序**，不重排。

## 4. 原型选择

《逐页内容》里每页已经是排好的版面，**不换皮时直接沿用**，只在换皮时按新皮规范重新组织同一批内容。

**原型只是参考，不是模具。** 编号要不要显、放哪；小字留在角上还是贴标题；页码换不换位置；这一页用两栏、下一页用行表，都合法。**没有必须前后一致的内部规律**——只有外壳要一致。
没有完全匹配的：

- 优先**换成最接近的原型**，别发明新组件。
- 实在不行才新增，新增的样式追加到 `<style>` 末尾，类名加前缀防撞。

## 5. 配图

- 默认**不配图**。用户要求配才配。
- 生成图（ImageGen）→ 四边**等量**裁 8% 去水印 → 缩到 760–1100 宽。
  ⚠️ 只裁右下会让构图偏心。
- 图片存 `ppt/<中文项目名>/assets/`，HTML 用相对路径引用。
- **不要引第三方图床域名。**
- 图框比例必须等于图片比例，否则 `object-fit:cover` 会裁掉两侧。

## 6. 自检

### 6.1 结构自检（不开浏览器）

```bash
# section 数量
grep -c '<section class="slide' "<中文项目名>-放映页.html"
# 每页是否都有 data-note
grep -c 'data-note=' "<中文项目名>-放映页.html"
# 是否残留第三方域名
grep -Eoi '<img[^>]+>' "<中文项目名>-放映页.html" | grep -Eoi '(https?:)?//[^/"'"'"' ]+' | grep -Eiv 'codebuddy|workbuddy'
```

三项数字对不上就回去改。

选了自带皮（波普拼贴 / 鎏金颁奖 / 卡通形象 / 贴纸插画）时，再加两条——契约见 `visual-library/_style-contract.md`：

```bash
# 裸 HEX 检查：组件规则里不应出现裸色值（@font-face / 图片路径行除外）
grep -nE '#[0-9A-Fa-f]{3,8}' "<中文项目名>-放映页.html" | grep -v 'fonts/' | grep -v 'assets/'
# 前缀检查：除引擎结构类（.slide/.hd/.kick/.ttl/.note/.r/.rf/.hud*/.notes*）外，
# 自定义类必须带 <id>- 前缀（如 .ag-*），肉眼扫一遍 <style> 段
```

### 6.1b 单调自检（截图之前先过，七条挂二即重排）

见 `../../../../docs/升级草案-视觉皮完全隔离-v3.3.md` 附则 A（判据见 J-35）。

```
□ 每页三秒内说得出主体？
□ 遮住主体后页面还读得懂吗？（读得懂 = 空洞）
□ 每张卡载荷率 ≥ 25%？
□ 同页同构元素 ≤ 3 个？
□ 每页有 ≥15% 面积的大块？且不超过 2 个？
□ 每 3 页至少 1 页出现深色块？
□ 连续 3 页没有重复同一栅格？
```

> 最有效的一条是**遮主体测试**：把角色遮住还读得懂的页，就是「纯文字块 + 一张贴纸」，必判单调。

### 6.1c 位置自检（截图之前先过，挂一问即重排）

见 `../../../../docs/升级草案-视觉皮完全隔离-v3.3.md` 附则 B（判据见 J-36）。逐张贴纸（角色 / 道具 / 头肩图）过一遍：

```
□ 遮住它，页面有变化吗？（没有 = 没落点）
□ 它压字了吗？压脸了吗？（压了 = 0 分）
□ 它是承载 / 关联 / 接触？三型都答不出 = 挪位
□ 它压的是该压的那层吗？（L3 贴纸压 L2 承托，不反）
□ 破框只有一处？裁切线在躯干、头还露 60%？
□ 右下 190×44 里没有字、没有脸、没有手？
```

> 三型距离：**承载**间隙 0（压在既有水平边上）；**关联**距角色头部 ≤120px 且在视线侧；**接触**间隙 ≤24px 或重叠 5–20%（>20% 是遮挡，<5% 是分离）。
> 最常见的错法不是放歪，是**悬空**——元素都在，但没跟任何东西发生关系。

### 6.2 视觉自检（必做）

```bash
"C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --disable-gpu \
  --hide-scrollbars --window-size=1280,720 --virtual-time-budget=3500 \
  --screenshot="shot-01.png" "file:///<urlencoded-html>#1"
```

每张图看三件事：

| 看什么 | 不合格的样子 |
|---|---|
| 溢出 | 文字出框、卡片被切、底部压到 HUD |

| 呼吸 | 字挤成一团、块贴边、留白被占满 |
| 忠实 | 对照所选皮 md 的色板表核对主色——色不对即退回，不许「看着差不多」 |

**没看过截图不算做完。** 至少看：首屏、末屏、每个章节页、最密的那一页。

## 7. 可选：上线

只有用户明确说「发出去」才做。资料库脚本的安装位置因机器而异，**不要写死路径**，先自己找：

```bash
# 在本机搜索导入脚本，找不到就如实说明，不要猜路径
find "$HOME/.workbuddy" "/c/Program Files" -name "import_html.py" -path "*library*" 2>/dev/null | head -3
```

找到后：

```bash
LIB="<上一步查到的 library 目录>"

# 质量门禁（固定 1280×720 舞台的告警属固有，可 ack）
python "$LIB/page/lint_page_quality.py" --html "<中文项目名>-放映页.html" \
  --ack "固定 1280x720 舞台等比缩放，多列栅格位于舞台内部"

# 导入 / 覆盖更新
python "$LIB/page/import_html.py" "<中文项目名>-放映页.html"
```

导入后 `data-page-node-id` 会被重写，评论锚点跨版本失效——**改版前先记下当前 nodeId**。
