# 动作风格提取 · 呆呆鲨卡通风

> 目的：替换 `cartoon-mascot` 的「指向 / 思考 / 慌张」三姿态。
> 那三张是**端正站立 + 单手指示**的汇报腔，与这份样张的动作语言不是一回事。
> 证据页：p1 p2 p3 p4 p6 p7 p8 p10 p11（p5 与 p3 同版式，p9 无角色）。

---

## 一、结论先写

这份样张的角色**从来不站着**。11 页里 9 页有角色，9 页全部与某个元素发生物理接触——压着数字、套在圈里、被杯子罩住、趴在标题条上、从画边探出。

**动作的全部信息量都在「她跟什么东西挨着」这件事上**，不在她摆了多好看的姿势。

---

## 二、六种动作式（逐页取证）

| 式 | 定义 | 证据 | 关键参数 |
|---|---|---|---|
| **抱 HOLD** | 双臂环抱一个道具，道具占画面 ≥12% | p1（抱奶茶杯）、p7（抱甜筒） | 双臂呈闭合弧，道具挡在胸前，脸从道具上方露出 |
| **举 RAISE** | 单臂上举，道具高于头顶 | p2（举小镜子照自己） | 上举臂与肩成 20–35°，头微仰，视线追着道具 |
| **趴 LIE** | 身体压在一条水平边上，纵轴与该边重合 | p3（趴在数字 01 上）、p4（趴在标题条上） | 腹部压在边上，双脚/尾向后翘起，下巴可搁在边沿 |
| **套 RING** | 身体穿过环形物，环遮住腰或肩 | p6（套救生圈） | 环的内径 ≈ 体宽 1.2 倍，双手搭在环沿 |
| **罩 COVER** | 道具从上方扣住头部，只露脸与手 | p10（冰淇淋杯罩头） | 只有头部与两只手出镜，其余全被遮 |
| **探 PEEK** | 只露半个身子在画边或块边缘之外 | p11（趴平摊开）、p3 右下大角色 | 身体被画边裁切，裁切线穿过躯干中段 |

> 六式之外没有第七种。**没有「站」这一式**——这是本次替换的核心。

## 三、被取出的参数（可量化的部分）

| 项 | 值 | 证据 |
|---|---|---|
| 躯干倾角 | 8–18°（无一张是 0°） | p1 右倾 ≈10°、p2 左倾 ≈15°、p4 几乎水平 ≈80° |
| 重心偏移 | ≥ 体宽 1/5，超出支撑面 | p2 举镜时重心明显偏左 |
| 与版面的接触率 | **9/9 = 100%** | 每张角色都压着/套着/被罩着某物 |
| 破框率 | 5/9 ≈ 56% | p3 右下、p4 右上、p10 右、p11 底部、p1 星框边缘 |
| 手部 | 3 指以内或鳍状，不画五指定型 | p1 抱杯的手是两团弧 |
| 腿/尾 | 简化为一团，无关节转折 | p3/p4/p11 全部 |
| 头身比 | 约 2 头身（头占全高 45–50%） | p1 实测头高 ≈ 全高的 47% |
| 腮红 | 必出现，两团，直径 ≈ 头宽 12% | 9/9 页 |
| 表情集 | 眯眼笑 / 张嘴笑 / 闭眼满足 / 睁圆呆萌 / 张嘴慌张（5 种） | p1 眯眼、p2 张嘴笑、p4 闭眼、p7 睁圆、p11 满足 |
| 视线 | 与文字区**相反**（角色看留白，不看字） | p2 角色朝左上、文字在右；p4 角色朝左、标题在左但视线越过 |
| 描边 | 深蓝紫 5px + 白 6px 外描边 + 柔影 | 全篇一致 |

## 四、动作 → 句型 的映射（替换旧表）

| 页面句型 | 用哪一式 | 为什么 |
|---|---|---|
| 封面 / 主张 | **抱**（把主题物抱在怀里） | 道具即主题，一眼知道这页讲什么 |
| 目录 / 清单 | **举**（举一个可指的东西） | 举高于头顶，视线自然引向列表 |
| 定义 / 说明 | **趴**（趴在内容块上） | 身体压住块，等于「这块归她管」 |
| 警告 / 坑 | **罩**（被问题扣住头） | 遮挡 = 受困，比慌张表情更有叙事 |
| 数据 / 量级 | **套**（套在环里） | 环 = 刻度，角色被刻度围住 |
| 结尾 / 收束 | **探**（被画边裁掉半个身子） | 退场感，比「站着比耶」安静 |

## 六、对现有素材的判定

现有三张（`cm-char-point / think / panic`）全部是**端正站立 + 单手指示**，属于被本文件否掉的那一类：

| 现有 | 为什么不能用 |
|---|---|
| `point` | 站直、右手前指——汇报腔，且手上没有任何道具，与版面零接触 |
| `think` | 站直、手托下巴——思考姿态成立，但仍是悬空站立 |
| `panic` | 站直、双手抬起——慌张靠表情，不靠遮挡，信息量低于「被罩住」 |

**结论：三张全部退役。** 新皮只用六式，且每式必须带承托物。

## 七、无新素材时的过渡做法（零成本，先止血）

在没有新姿态图之前，用**构图**伪造接触关系，可以把「站着」改造成「趴着 / 探出」：

1. **趴**：把角色压到一条水平边（数字、色块、标题条）上，让该边穿过她的躯干中段，并在她身下补一枚椭圆接触影。
2. **探**：把角色的 z-index 降到版面块之下，只让头部与肩部从块的上沿露出来。
3. **罩**：用一个纯色块盖住角色头部以下，只留脸——但块必须有语义（不是纯遮挡）。

三种都只能救急。**抱 / 举 / 套 三式必须有道具，靠构图伪造不出来，只能重新绘制。**
