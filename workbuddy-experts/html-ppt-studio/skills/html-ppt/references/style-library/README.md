# 风格库

每个风格 = 一份 md 规范 + 一份可直接跑的参考实现。

| id | 名称 | 语感 | 适合 | 状态 |
|---|---|---|---|---|
| [`pop-collage`](pop-collage.md) | 波普拼贴 | 强对比、硬边、贴纸感、有点吵 | 汇报、复盘、对内宣讲、要有记忆点的场合 | ✅ 已沉淀 |
| — | — | — | — | 待他提供 |

## 加新风格的规矩

1. 必须有一份**真实跑通的 HTML**（不是描述），命名为 `<id>.reference.html`。
2. 写 `<id>.md`，至少包含：调性、色板、字号阶、视觉语法、安全区、组件清单、页面原型、交互、坑。
3. 在本表加一行。
4. 不要把新风格塞进旧风格的 md 里——一个文件只管一个风格。

## 选风格的判断

- 他说了风格名 → 直接用。
- 他没说 → 默认 `pop-collage`，并问一句「还是换别的」。
- 他说「你看着办」→ 选 `pop-collage`，别纠结。
- 他说要一个库里没有的 → 明说没有，让他给参考（截图 / 网站 / 现有 HTML），**不要现编**。
