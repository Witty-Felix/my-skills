# 输入与导出异常处理

| 情况 | 处理方式 | 输出限制 | 停止条件 |
|---|---|---|---|
| 未提供专有词 | 直接按原始记录整理，不猜测同音词 | 专有词仅以原文为准 | 无 |
| 跳过常用词库 | 只使用本次明确提供的词 | 无历史词库校正 | 无 |
| 会议信息缺失 | 标为“原始记录未明确” | 不补写元数据 | 无 |
| 原文存在矛盾 | 分别记录并列入 R 编号 | 不给最终裁决 | 矛盾影响核心结论且用户要求确定结论 |
| 内容无法读取或严重残缺 | 说明可读范围并要求补充 | 不能保证完整性 | 无法提取足以支撑纪要的内容 |
| Word 导出不可用 | 先交付结构化会议纪要文本 | 未生成 .docx | 用户仅接受 .docx 且无法恢复导出 |
| 术语证据不足 | 保留原文并标“待核对” | 不替换 | 无 |
