# 专有词收集与受控校对

## 询问模板

```text
为避免同音转写错误，请确认是否沿用常用词库，并补充本次会议专有词：
【人名】
【团队 / 公司 / 客户】
【项目 / 产品 / 内部简称】
【技术 / 行业 / 业务词】
【容易听错或必须统一的写法】
```

## 规则

用户填写的标准词只用于比对原始记录，不代表会议提及。仅在同音、近音、英文大小写、连写拆写或明显错别字与上下文共同支持时统一写法。人名需由发言位置、称呼、角色或上下文稳定对应；数字、日期、金额、比例、型号和截止时间不依据词库猜测修正。避免全局替换。证据不足时保留原文并标“待核对”。

## 核对说明

只列有实际影响的修正与疑点；没有时写“本次未发现需要单独说明的名称或术语问题”。

| 原始转写 | 纪要采用写法 | 依据 | 状态 |
|---|---|---|---|
| 原始记录中的写法 | 统一后的写法 | 用户词库 + 上下文 / 原文明确写法 | 已校正 / 待核对 |

## 常用词库维护

默认只使用当前会话中用户提供或明确允许沿用的词库。用户提出保存、新增、修改或删除常用词库时，先展示逐项变更、写入位置、影响与回退方式，等待明确确认；未获确认时不写入持久词库。
